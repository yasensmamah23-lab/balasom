# مركز بلسم الشفاء للتمريض المنزلي (Balsam Al-Shifa Home Nursing)

الموقع الرسمي لـ **مركز بلسم الشفاء للتمريض المنزلي** - تقديم خدمات التمريض الرعاية المنزلية المعتمدة في محافظة الزرقاء وعمان الغربية.

## الخدمات المقدمة:
* التمريض المنزلي الشامل والمستمر.
* رعاية كبار السن وإدارة الحالات المزمنة.
* العناية بالجروح المتقدمة وقدم السكري.
* رعاية ما بعد العمليات الجراحية.
* العلاج الوريدي والسحب المخبري المنزلي.

## التراخيص والاعتماد:
* مرخص ومسجل لدى وزارة الصحة الأردنية.
* جميع الكوادر ممرضون وممرضات قانونيون (Registered Nurses).
